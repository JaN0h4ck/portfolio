- My Bachelors Thesis, made in 2025
- Extending a barebones editor for the Vektoria game engine to support more node Types
- **Used Libraries**: Vektoria (24.07) and Dear ImGui
- Implementing Inspector Widgets for:
  - Translation
  - Rotation
  - Scale
  - Lights: Radial, Spot and Directional
  - Geometry: Arrow, Cone, Cube, Cylinder, Dodecaherdon, Dome, Elipsoid, Icosahedron, Octahedron, Pyramid
    - +Modal Dialog for creating the Geometry with it's properties
  - Audio
  - Camera
  - Emitter
  - Image
  - Texture
  - Placement (Similar to Blenders Empty or Godots Node3D)
  - Materials
- Further Functionality
  - Deleting Nodes from Scene Tree
  - Adding Nodes to Scene Tree
- Grade: 1.7 (A-)
